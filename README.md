# WordBook · 网页双语生词错题本（Chrome 插件）

浏览网页时遇到不认识的单词、短语或句子，通过**划词选取 / 右键菜单 / 快捷键**即可一键自动翻译为**简体中文**，并连同原文上下文语境一起收录到你的专属「错题本」中。

## 核心功能

1. **三种快捷收录方式**
   - **网页划词浮动按钮**：选中网页任意单词、短语或句子，点击「译并记」，即时显示双语对照卡片并收录。
   - **右键菜单**：选中文本后右键 → `添加到 WordBook 生词错题本`。
   - **快捷键**：选中文本后按 `Alt + Shift + S`（Mac 为 `Option + Shift + S`）。
2. **自动双语对照（简体中文）**
   - 收录时自动识别源语言并翻译为简体中文，单词还会附带音标与词性释义。
   - 内置免配置自动翻译（Google Translate + MyMemory 备选），也支持在设置中配置自定义 OpenAI 兼容大模型 API。
3. **像错题本一样的语境与复习系统**
   - 自动抓取生词所在的**上下文例句**与**来源网页标题/链接**，复习时可高亮回看语境。
   - 再次在网页上遇到已掌握的单词并点击收录时，会自动将「遇到次数 +1」并重新放回错题本提醒复习。
   - **错题抽查（闪卡模式）**：支持「看原文想中文」和「看中文想原文」双向抽查，记录遗忘次数与掌握进度。
   - **导出与备份**：支持导出 UTF-8 CSV（可直接用 Excel 打开或导入 Anki）以及 JSON 完整备份导入。

## 如何在 Chrome 中安装使用

1. 打开 Chrome 浏览器，在地址栏输入并访问 `chrome://extensions/`。
2. 打开右上角的 **开发者模式（Developer mode）** 开关。
3. 点击左上角 **加载已解压的扩展程序（Load unpacked）**。
4. 选择本目录：`/Users/I567329/Documents/GitHub/wordbook`。
5. 建议将 **WordBook** 固定（Pin）到浏览器工具栏，方便随时查看最近生词或进入完整错题本。
